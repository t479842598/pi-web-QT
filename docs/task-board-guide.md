# 任务看板（Beta）使用指南

> 适用版本：pi-web ≥ 0.9.16-beta（任务看板为 Beta 功能，仅桌面端可用）

任务看板把「给 agent 派活」变成一条可跟踪、可验收、可归档的流水线：
**创建 → 启动 → 执行 → 待验收 → 合并 → 已完成**。每个任务在独立 git worktree 分支中运行 agent，互不干扰。

---

## 1. 打开看板

桌面端（非移动端）点击标题栏的**看板按钮**（四宫格图标），在聊天与任务看板之间切换。

- 看板标题带 **Beta** 徽章
- 移动端不显示看板入口
- 切换语言（中文/English）或深浅主题，看板自动跟随

## 2. 看板四列

| 列 | 包含状态 | 含义 |
| --- | --- | --- |
| **待办** | `todo` | 已创建，等待启动 |
| **进行中** | `queued` / `preparing` / `running` | 排队中 / 创建 worktree 中 / agent 执行中 |
| **待处理** | `awaiting_input` / `review` / `merging` / `failed` | 需要你处理：等待输入、待验收、合并中、失败 |
| **已完成** | `done` / `canceled` | 完成或取消（取消默认隐藏） |

> 提示：任务从「待处理」进入「已完成」前，顶部标题栏会出现**红色待处理计数徽章**；窗口不在前台时还会收到**系统通知**。

## 3. 创建任务

1. 点击「**新建任务**」
2. 选择**项目**（默认当前打开的项目）
3. 填写**标题**（简短）与**任务说明**（prompt，描述 agent 要完成的工作）
4. 点「保存」

**模板**：常用任务可点「存为模板」；下次新建时点模板名直接套用，可随时删除。

## 4. 启动任务

三种方式：

- 点击卡片上的「**开始**」按钮
- 把待办卡片**拖到「进行中」列**（拖拽时有跟随预览，拖到目标列会高亮提示「松手启动」）
- 点工具栏「**全部启动**」排队当前项目的全部待办任务

启动后引擎自动：

1. 在项目旁创建 worktree 目录（`<项目名>-worktrees/task-<id>-<slug>`）
2. 在其中创建独立分支 `task/<id>-<slug>`
3. 在 worktree 中启动 agent 执行任务说明

> 若项目配置了「初始化命令」（如 `pnpm install`），会在 agent 启动前执行。

## 5. 执行与等待

- 运行中可随时点「**取消**」
- agent 需要你输入时，任务翻转为「**等待输入**」状态
- 卡片上会实时显示运行进度与分支名

## 6. 验收（待处理）

agent 完成后任务进入「**待处理**」列。点击卡片打开**详情抽屉**：

- **变更文件**：列出任务改动的文件与增删行数
- **Diff**：点文件名查看该文件的差异
- **时间线**：完整记录任务从创建到现在的每一步（创建 → 排队 → 准备 → 启动 → 待验收 → …）
- **预检红绿灯**：若项目配置了「预检命令」（如 `npm test`），验收时显示通过/失败结果

两个选择：

| 操作 | 说明 |
| --- | --- |
| **合并** | 接受产出。可选择自动/手动提交信息、是否合并后删除 worktree；合并由 agent 在会话内完成，成功后任务进入「已完成」并记录提交号 |
| **退回** | 填写反馈退回给 agent 继续修改（任务回到执行流程） |

## 7. 归档与清理

- 已完成/失败/取消的任务可点「**归档**」（卡片默认变淡）
- 已归档任务默认隐藏，在「筛选」中勾选「显示已归档」可查看，可「取消归档」
- 「**全部归档**」一键清空已完成列
- 筛选也可切换「显示已取消」

## 8. 失败与重试

- 失败任务卡片显示红色错误信息，点「查看」可看详情
- 「**重试**」：以新代际重新执行（清除上次错误）
- 「**编辑**」后重新启动
- 已取消的任务可「**重新排队**」回到待办列

## 9. 任务设置（按项目）

点看板标题栏的「**任务设置**」（独立于主设置弹窗），按项目配置执行行为：

| 设置 | 说明 |
| --- | --- |
| 自动处理排队任务 | 开启后任务一排队即自动启动（默认开） |
| 最大并发任务数 | 每项目同时执行上限（0 = 不限） |
| 合并策略 | 合并提交（merge commit）或压缩提交（squash） |
| 合并后删除 worktree（默认） | 合并完成后自动清理 worktree 与分支 |
| 预检命令（验收检查） | 进入待验收前在 worktree 中运行，输出红绿灯（如 `npm test`） |
| 初始化命令 | agent 启动前执行（如 `pnpm install`） |
| 阶段提示词 | 执行 / 重试 / 退回 / 合并各阶段附加指令 |

## 10. 查看任务会话

任务卡片或详情抽屉的「**查看会话**」显示任务 agent 的会话信息；任务会话与其他会话一样存储在 `~/.pi/agent/sessions/`，可在会话列表直接打开查看完整对话。

## 技术说明与限制（Beta）

- 任务数据存储于 `~/.pi/agent/tasks/`（JSONL，原子写），删除任务即删除记录
- 每个任务独立 worktree 分支执行；**任务 agent 被明确约束不得提交/推送其他分支或工作区改动**
- 引擎由服务器进程持有（单实例锁），服务重启后自动恢复中断任务（标记为失败/中断，可重试）
- 已知限制：
  - 仅桌面端可用
  - 「等待输入」依赖 agent 主动请求输入；自主模式下 agent 通常直接完成，较少进入该状态
  - 合并由 agent 在会话内完成，耗时取决于改动量；主 checkout 有未提交改动时 shell 合并会被拒绝（安全保护）
