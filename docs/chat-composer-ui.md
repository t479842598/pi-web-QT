# Chat Composer UI

## 设计目标

聊天输入区以 `isWittHere/pi-web-desktop` 的双层、低对比度 Composer 为基线：同一面板承载文本编辑区和工具栏，交互保持克制，不使用独立的外置发送/附件轨道。

## 结构与交互

- `.chat-input-shell` 包含编辑区、bash 状态与工具栏；使用 `8px` 圆角、单层边框和 `--bg-secondary` 背景。焦点态仅提高边框强调色。
- 桌面端文本区最小高度为 `50px`；发送操作是工具栏末端的 `24px` 图标按钮。附件、模型、思考、工具、压缩、声音、队列导入与停止操作保留当前项目原有能力。
- 流式运行时，steer/follow-up 变为输入面板右上方的双图标浮层，保留原有队列行为；文本区仍可输入。
- 窄屏沿用同一面板层级，工具栏变为两列布局；iOS 输入字号由全局移动端规则保持为 `16px`，避免触发浏览器缩放。
- slash 命令、`@` 文件引用、输入历史、附件预览、队列恢复/导入、模型与工具配置均不改变数据和调用链。

## 维护约束

- Composer 色彩必须使用全局 CSS token，以保证 Pi TUI 主题切换同步生效。
- 不在视觉组件中增加网络请求、消息发送逻辑或会话协议分支。
- 输入区视觉基线参考仓库的提交 `80d21fc84b9c5b193b3ae947818fa001e30be032`；后续调整应先对比其 `components/ChatInput.tsx` 与 `app/globals.css`。
