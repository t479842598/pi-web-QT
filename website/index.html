客户端

三端同一套会话。点任意一张放大。

流式会话

SSE 推送正文、工具调用、思考和错误，断线后还能接上正在跑的回合。

项目与文件

按目录加载项目，浏览 Diff、图片、PDF、DOCX，会话可以分叉和导出。

模型与技能

在客户端里管模型、OAuth、连通性、Skills 和插件，不用改配置文件。

Worktree

同一仓库开多条工作树，任务看板把每条任务放进独立分支里跑。

开始

不装客户端也可以先跑网页服务。默认只听 127.0.0.1。

npx @qt4798/pi-web@latest
npm install -g @qt4798/pi-web
pi-web
git clone https://github.com/t479842598/pi-web-QT.git
cd pi-web-QT
npm ci
npm run dev

安装版打开 http://127.0.0.1:30141。源码开发服使用随机端口，看启动日志。
